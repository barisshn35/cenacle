# Cenacle with Docker Compose

> This folder is `deploy/compose/` of the main repository,
> [Cenacle-TR/cenacle](https://github.com/Cenacle-TR/cenacle). The repository
> [Cenacle-TR/cenacle-docker](https://github.com/Cenacle-TR/cenacle-docker) is a read-only copy of it, updated
> from the main repository. Install, build, report issues and send changes there.

The production stack (`prod.yml`), `install.sh` and the files they use. Install from a release of the main repository, whose GitHub Releases page carries `install.sh`, the compose archive and the signed `SHA256SUMS`: [docs/install/README.md](https://github.com/Cenacle-TR/cenacle/blob/main/docs/install/README.md).
