# Cenacle desktop app

> This folder is `desktop/` of the main repository,
> [Cenacle-TR/cenacle](https://github.com/Cenacle-TR/cenacle). The repository
> [Cenacle-TR/cenacle-desktop](https://github.com/Cenacle-TR/cenacle-desktop) is a read-only copy of it, updated
> from the main repository. Install, build, report issues and send changes there.

The Cenacle app for Windows and Linux (Electron). It pairs with an organization's Cenacle server and opens that server's web app; sign-in, data and updates come from the server. Installing and managing it: [docs/install/desktop.md](https://github.com/Cenacle-TR/cenacle/blob/main/docs/install/desktop.md) and [docs/desktop/](https://github.com/Cenacle-TR/cenacle/tree/main/docs/desktop). It builds from the main repository, which holds the pnpm workspace it uses.
