# Cenacle bot SDK for Go

> This folder is `sdk/go/` of the main repository,
> [Cenacle-TR/cenacle](https://github.com/Cenacle-TR/cenacle). The repository
> [Cenacle-TR/cenacle-sdk-go](https://github.com/Cenacle-TR/cenacle-sdk-go) is a read-only copy of it, updated
> from the main repository. Install, build, report issues and send changes there.

```sh
go get github.com/Cenacle-TR/cenacle/sdk/go@v1.0.0
```

The module path is the main repository's (`github.com/Cenacle-TR/cenacle/sdk/go`), so `go get` works only from there, never from the copy. Each release `vX.Y.Z` has the SDK as `sdk/go/vX.Y.Z`. Usage and the protocol: [sdk/README.md](https://github.com/Cenacle-TR/cenacle/blob/main/sdk/README.md), [docs/integrations](https://github.com/Cenacle-TR/cenacle/blob/main/docs/integrations/README.md).
