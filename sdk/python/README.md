# Cenacle bot SDK for Python

> This folder is `sdk/python/` of the main repository,
> [Cenacle-TR/cenacle](https://github.com/Cenacle-TR/cenacle). The repository
> [Cenacle-TR/cenacle-sdk-python](https://github.com/Cenacle-TR/cenacle-sdk-python) is a read-only copy of it, updated
> from the main repository. Install, build, report issues and send changes there.

A client for the Cenacle API and handlers for slash commands, interactions and event subscriptions, with the signature checked. Standard library only; Python 3.10 or later.

```sh
pip install "git+https://github.com/Cenacle-TR/cenacle@v1.0.0#subdirectory=sdk/python"
```

Pick the version of your server. The package is not on PyPI. Usage and the protocol: [sdk/README.md](https://github.com/Cenacle-TR/cenacle/blob/main/sdk/README.md), [docs/integrations](https://github.com/Cenacle-TR/cenacle/blob/main/docs/integrations/README.md).
